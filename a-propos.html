À propos

Une agence à taille humaine.

My-Apps est née d'un constat : les petites entreprises ont besoin d'un vrai site, pas d'un modèle impersonnel ni d'un devis à cinq chiffres.

Notre approche

Nous utilisons l'intelligence artificielle pour accélérer ce qui peut l'être : trame des pages, premières versions de textes, variantes graphiques. Tout le reste est fait par une personne : le choix des mots, le design final, les tests et le suivi.

Nos engagements

  • Transparence : prix annoncés avant de commencer, pas de frais cachés.
  • Propriété : le site, son code et son nom de domaine vous appartiennent.
  • Simplicité : vous apprenez à modifier vos contenus sans nous.
  • Respect des données : conformité RGPD, hébergement en Europe sur demande.
